# Contributing to Kilimanjaro

Thank you for using Kilimanjaro. This page explains how to report problems and suggest changes.

## Report a bug

Open an issue on the repository the problem is in and include:

- the version you use and your language or runtime version
- the smallest code that reproduces the problem
- the full error, including its `code` and request id if there is one

## Suggest a change

Open an issue that says what you want to do and why. If you already have a fix, open a pull request and link the issue.

## Security issues

Do not open a public issue. See [SECURITY](https://github.com/k9o-community/.github/blob/main/SECURITY.md).
